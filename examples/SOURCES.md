# Example clips: sources

All six are CC0 (public-domain dedication) photographs from Wikimedia Commons, the
Unsplash-era uploads. No attribution is required; this file records where each came
from. Each was resized to 624x416 (beard: 416x624), run through this app unchanged
(tools/make-examples.mjs, 0.45 Mbps H.264, 6 s) and the still kept as the poster.
